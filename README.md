# Pocket Ledger

**A clear view of where your money goes.**

🔗 Live demo: https://deekshith1327.github.io/pocket-ledger/

## Features

- Record income and expenses
- View totals and recent transactions
- Filter the ledger by transaction type
- Keep entries in browser storage
- Responsive interface for desktop and mobile

## Run locally

Requires Node.js 18 or later.

```sh
npm start
```

Open [http://localhost:3000](http://localhost:3000). The local Node server also saves app state to `data.json`; the GitHub Pages version stores data in this browser. This is a learning project, not a bank-connected financial service.
